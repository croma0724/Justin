Lesson2:   solve first degree equation
	aX + b = 0   => X = -b / a
	
1. Invalid equation cases:  
	1.1 	a = 0 =>    b = 0 invalid, unless b = 0
    1.2 	b = 0 =>    aX = 0 => X = 0 if a != 0, otherwise invalid
    
	Equation valid when:    
		a != 0 and b != 0    
		a != 0 and b = 0     => root: X = 0 
	
2. Requirements:
2.1	- provide a and b equation parameters. Cases:
2.1.1    a and b are fixed arguments
2.1.2    a and b are read from the console
	  	
2.2	- validate a and b as defined by 1.1 and 1.2 conditions
